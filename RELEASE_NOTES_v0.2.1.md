# MetrixRTA 0.2.1 — pre-release

MetrixRTA 0.2.1 is a Windows x64 pre-release focused on stepped-frequency distortion measurement and audio-I/O reliability.

## Highlights

- New THD / THD+N vs Frequency measurement
- FFT-bin-aligned frequency steps at 1, 1/3, 1/8, or 1/24 octave spacing
- Live two-channel THD and THD+N curves with named overlay sources
- Reliable step transitions using input-tone detection and fresh FFT capture windows
- Automatic progress tracking and STOP after the final step
- Global bandwidth-boundary display control
- Improved WASAPI format-list persistence
- Screenshots saved as `Measurements/<DUT>/ScreenshotN.png`
