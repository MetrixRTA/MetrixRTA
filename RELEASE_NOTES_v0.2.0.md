# MetrixRTA 0.2.0 — pre-release

This is an early public preview of MetrixRTA for Windows x64.

## Highlights

- Real-time FFT spectrum analysis with mouse zoom and navigation
- THD, THD+N and THD+N vs time measurements
- CCIF and SMPTE intermodulation measurements
- AM level and 31-tone multitone TD+N modes
- Independent ASIO and WASAPI input and output
- Sample rates up to 768 kHz with compatible hardware
- Two-channel overlay and separate-channel displays
- Centralized results table with calculation details
- Spectrum averaging, overlays, weighting and configurable analysis bandwidth
