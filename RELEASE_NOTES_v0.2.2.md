# MetrixRTA 0.2.2 — pre-release

MetrixRTA 0.2.2 is a Windows x64 pre-release focused on a faster, more responsive interface and expanded measurement presentation tools.

## Highlights

- Faster GUI response with consolidated updates and fewer redundant redraws
- Stable spectrum viewport during mode and control changes
- Per-channel Offset and Norm calibration with dBr presentation
- Persistent movable text and arrow annotations on the spectrum
- Native Windows font and arrow-color selection
- Configurable screenshot filename prefixes and automatic numbering
- Optional control-panel inclusion in screenshots
- Independent capture and generator control during normal operation and device reconnection
