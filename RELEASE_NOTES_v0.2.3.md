# MetrixRTA 0.2.3 — pre-release

MetrixRTA 0.2.3 is a Windows x64 pre-release focused on a more compact measurement workspace, clearer result presentation, and configurable spectrum appearance.

## Highlights

- Compact draggable result panels displayed directly over each channel spectrum
- Collapsible per-channel panels with positions restored from the configuration
- Clickable measurement values for detailed information
- Larger spectrum area after removal of the former lower results table
- Day/night spectrum theme with adaptive axes, grid, labels, panels, and traces
- Screenshot copying directly to the Windows clipboard
- Screenshot option to include or exclude both control panels
- More compact and informative input, output, and measurement status presentation
- Further GUI redraw consolidation and startup flicker reduction
